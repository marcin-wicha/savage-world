# Edge data attribution

`swade.yml` contains mechanical edge data derived from the official SWADE
Foundry Virtual Tabletop system:

- Source: <https://gitlab.com/peginc/swade>
- Copyright: Pinnacle Entertainment Group
- License: Apache License 2.0 (see `LICENSE`)

The tracked data is limited to edge names, categories, ranks, requirements,
repeatable flags, and source page references. Rulebook descriptions are kept in
ignored private overlays and must be derived from a legally owned copy.

Savage Worlds, SWADE, and Fantasy Companion are trademarks of Pinnacle
Entertainment Group. This project is not affiliated with or endorsed by
Pinnacle Entertainment Group.

Fantasy Companion edge data is not included in this repository. Files placed in
Files placed in `private/` are ignored by git and must be derived from a
legally owned copy of the relevant rulebook. This includes Fantasy Companion
data and description overlays.
