# Skill data attribution

`swade.yml` contains mechanical skill data derived from the official SWADE
Foundry Virtual Tabletop system:

- Source: <https://gitlab.com/peginc/swade>
- Copyright: Pinnacle Entertainment Group
- License: Apache License 2.0 (see `LICENSE`)

The tracked data is limited to skill names, linked attributes, core-skill status,
and source page references. Rulebook descriptions are kept in ignored private
overlays and must be derived from a legally owned copy.

Savage Worlds, SWADE, and Fantasy Companion are trademarks of Pinnacle
Entertainment Group. This project is not affiliated with or endorsed by
Pinnacle Entertainment Group.

Fantasy Companion skill data is not included in this repository. Files placed
in `private/` are ignored by git and must be derived from a legally owned copy of
the relevant rulebook. This includes description overlays.
