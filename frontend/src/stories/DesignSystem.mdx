# Savage Worlds design system

This Storybook is the visual contract for the character builder. Components are
built with [shadcn/ui](https://ui.shadcn.com/) and Tailwind CSS, and live in
`src/components/ui`.

## Principles

- Prefer semantic tokens such as `bg-background`, `text-foreground`,
  `text-muted-foreground`, and `border-border` over raw palette classes.
- Keep components accessible by default: labels, focus states, keyboard
  behavior, and sensible disabled states.
- Compose small primitives into feature UI instead of adding feature-specific
  styles to the primitives.
- Every reusable component should have at least one story showing its main
  states.

## Foundations

The theme is a high-contrast black-and-white palette inspired by Shadowdark:
near-black surfaces, warm off-white text, and no decorative color accents.
Pirata One provides the display headings; Geist handles UI and body text. Light
and dark tokens are defined in `src/index.css`; use the theme control in the
Storybook toolbar to inspect both modes.

## Usage

```tsx
import { Button } from '@/components/ui/button'

export function SaveCharacter() {
  return <Button>Save character</Button>
}
```

## Adding components

Use the shadcn wrapper from `frontend/`:

```bash
pnpm ui:add dialog select
```

The wrapper runs the shadcn CLI, writes primitives to `src/components/ui`, and
creates a co-located baseline story. Replace the generated `defaultArgs` with
realistic props and states before considering the story complete.

## Story conventions

- Use `Design System/<Component>` for primitives.
- Set `tags: ['autodocs']` so the docs page is generated.
- Cover default, variants, sizes, disabled, and any important edge states.
- Use `parameters.layout = 'centered'` for small primitives and a wider layout
  for composed examples.
